RawidMapChecker User Guide

A tool for visually reviewing candidate tracks extracted by the analysis pipeline and recording whether the emulsion track physically exists on both sides. This guide walks a first-time user through the whole process.

01

What this tool does

The offline manual check covers two pairs of images: a muon track and its reference track, and a muon's extrapolated position and its reference track. RawidMapChecker shows you these candidates one at a time, with their position and angle, so you can look at the corresponding microscope image and judge whether a track (a grain of emulsion) actually exists there. Your judgment — one of six choices — is written to a plain text file.

These judgments feed into downstream quality checks and selection. If you're not sure, don't force a call — use "Cannot judge."

02

Before you start

  • Python 3 installed on your machine (Windows or macOS). If you used the official installer, tkinter is already available.
  • The RawidMapChecker.py file itself (you'll be given this).
  • The *_rawidmap.txt file you're assigned to check (for your ECC/plates — your analysis lead will tell you which one).
Quick check

Open a terminal and run python3 -m tkinter (on Windows, python -m tkinter). If a small test window pops up, you're ready to go.

03

Launching it

  1. Put RawidMapChecker.py in a working folder.
  2. Open a terminal in that folder and run:
    OSCommand
    Windowspython RawidMapChecker.py
    macOSpython3 RawidMapChecker.py
  3. A file picker opens — choose the *_rawidmap.txt file you were assigned.
  4. If a matching *_result.txt already exists, you'll be asked to choose one of three options.
    OptionWhen to use it
    AppendContinue where you left off last time (usually this one)
    OverwriteStart over from scratch (only if you're fine losing the existing results)
    New file (numbered)Keep the previous results and start a fresh, separately numbered file

VPH display on prediction rows

An extrapolated (prediction) track has no photo information of its own, so VPH1(PH) / VPH2(PH) instead show the values from the Muon track with the same event number, drawn in orange as a reference value (a note also appears under the table). If no Muon track with that event number exists, the fields stay at -1.

05

Making a judgment

Using the position and angle shown in the table, check the corresponding microscope image and pick one of the following. Click with the mouse, or press the matching number key (1–6).

KeyOption (exact on-screen text)Meaning
1Both existsThe track exists on both the lens side and the stage side
2Only the lens side exists.Only the lens-side track is there
3Only the stage side exists.Only the stage-side track is there
4Neither exists.No track visible on either side
5Cannot judge.Can't tell — e.g. the image is unclear
6Add comments.None of the above quite fits — a free-text comment box opens (Enter to confirm, Esc to cancel)

Choosing an option automatically advances to the next row. You can also go back and re-answer a row at any time — the new choice simply overwrites the saved one.

07

Saving

  • Every time you make a judgment, it's saved automatically — there's no manual save step.
  • The results file is named by replacing the trailing _rawidmap in the input filename with _result (e.g. btrklist4_rawidmap.txt → btrklist4_result.txt), in the same folder as the input.
  • You can stop at any time — click "Finish (Save & Exit)" or just close the window. Next time, open the same input file and choose "Append" to pick up exactly where you left off.
08

Troubleshooting

"eventid ... not found in ... view"

Event search only looks within the currently selected mode (Muon or Reference). If the row you're looking for is in the other mode, switch modes (top right) first, then search again.

The judgment buttons are greyed out

There are no rows for the currently selected mode (e.g. you switched to Reference but the file has no Reference rows). Switch to the other mode.

The window won't open, or you get an error

Check your Python version and that tkinter is available (see 02 Before you start). If that doesn't fix it, contact whoever gave you the tool and include the full error message.
