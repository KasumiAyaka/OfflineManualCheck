NINJA E71a

RawidMapCheckerの使い方

解析パイプラインが抽出した飛跡候補を1件ずつ目視確認し、乳剤の両面に飛跡が実在するかを記録するためのツールです。この文書は、初めて使う人でも一通り操作できるようにまとめたものです。

対象読者NINJA解析に参加する大学院生・研究者
必要環境Python 3（tkinter同梱）。追加インストール不要
配布ファイルRawidMapChecker.py 1本
対応OSWindows / macOS

01

このツールは何をするものか

オフラインマニュアルチェックでは、ミューオンとそのリファレンストラック、およびミューオンを外挿した位置とそのリファレンストラックについて、画像を確認します。RawidMapCheckerは、これら1件ずつの位置・角度情報を画面に表示し、あなたがマイクロスコープの画像などを見て「その位置に本当に飛跡（乳剤の粒）が存在するか」を6択で判定し、結果をテキストファイルに記録するためのツールです。

判定結果は解析の品質チェック・後段の選別に使われます。迷ったときは無理に判断せず「Cannot judge.」を選んでください。

02

準備するもの

  • Python 3 がインストールされたPC（Windows / macOS どちらも可）。公式インストーラを使っていれば tkinter は最初から使えます。
  • RawidMapChecker.py ファイル本体（担当者から配布されます）。
  • チェック対象の *_rawidmap.txt ファイル（担当のECC・プレートに対応するもの。解析リーダーから指示されます）。
動作確認

ターミナル（Windowsはコマンドプロンプト/PowerShell、Macはターミナル.app）で python3 -m tkinter（Windowsは python -m tkinter）を実行し、小さなテストウィンドウが開けば準備完了です。

03

起動方法

  1. RawidMapChecker.py を作業フォルダに置く。
  2. ターミナルでそのフォルダに移動し、次のコマンドを実行する。
    OSコマンド
    Windowspython RawidMapChecker.py
    macOSpython3 RawidMapChecker.py
  3. ファイル選択ダイアログが開くので、チェック対象の *_rawidmap.txt を選ぶ。
  4. 同名の *_result.txt（結果ファイル）が既にある場合、以下の3択が出る。
    選択肢いつ使うか
    Append前回の続きから作業する（通常はこれ）
    Overwrite最初からやり直す（結果を消してよい場合のみ）
    New file (numbered)前回の結果は残したまま、別ファイルとして新規に始める

prediction行のVPH表示について

外挿（prediction）トラックは自身の写真情報を持たないため、VPH1(PH) / VPH2(PH)には、同じイベント番号の実在（Muon）トラックの値がオレンジ色の参考値として代わりに表示されます（テーブル下に注釈も出ます）。同じイベントの実在トラックが見つからない場合は-1のまま表示されます。

05

判定の選び方

テーブルに表示された位置・角度をもとにマイクロスコープの画像を確認し、以下から1つ選びます。マウスでクリックするか、キーボードの数字キー（1〜6）でも選べます。

キー選択肢（画面表示のまま）意味
1Both existslens側・stage側の両面に飛跡が存在する
2Only the lens side exists.lens側のみ飛跡が存在する
3Only the stage side exists.stage側のみ飛跡が存在する
4Neither exists.どちらの面にも飛跡が見当たらない
5Cannot judge.画像が不鮮明等で判断できない
6Add comments.上記に当てはまらない場合。自由記述のコメント欄が開く（Enterで確定、Escで取り消し）

選ぶと自動的に次の行へ進みます。前の行に戻って選び直すことも可能で、その場合は選択が上書き保存されます。

07

保存について

  • 判定するたびに自動的に保存されます。手動での保存操作は不要です。
  • 結果ファイルは入力ファイル名の末尾を _rawidmap → _result に置き換えた名前（例: btrklist4_rawidmap.txt → btrklist4_result.txt）で、入力ファイルと同じフォルダに作られます。
  • 作業を中断したいときは、いつでも「終了 (Save & Exit)」またはウィンドウを閉じて構いません。次回同じ入力ファイルを開き「Append」を選べば、続きから再開できます。
08

困ったときは

「eventid ... not found in ... view」と出る

イベント検索は選択中のモード（Muon / Reference）の中だけを探します。目的の行が別モードにある場合は、右上でモードを切り替えてから検索してください。

判定ボタンが押せない（グレーアウトしている）

選択中のモードに該当する行が1件もありません（例: Referenceを選んだがファイルにReference行が無い）。もう一方のモードに切り替えてください。

ウィンドウが開かない・エラーが出る

Pythonのバージョンやtkinterの有無を確認してください（02 準備参照）。解決しない場合は配布元の担当者に、表示されたエラーメッセージ全文を添えて連絡してください。
